# Raden Hanif Abdul Hakim — Personal Portfolio

Modern, interactive, and responsive portfolio website built with **React**, **Vite**, **Tailwind CSS**, and **Framer Motion**.

---

## ✨ Features

- **Interactive Lanyard ID Card**: Draggable 3D lanyard ID badge simulation powered by Framer Motion.
- **Projects Showcase**: Interactive project cards & detail modal featuring Sweet Dessert, Tanya Kampus, and Web Human Capital.
- **Experience Timeline**: Journey covering internships at Syaamil Group, Independent Study, and organizational leadership.
- **Skills Matrix**: Categorized tech stack covering Frontend, Backend, Tools, and Methodologies.
- **Direct Contact**: Integrated contact form and verified links to GitHub, LinkedIn, and Instagram.
- **Dynamic Animations**: Smooth split-text reveal, magnetic cursor-following buttons, and fluid ambient background blobs.

---

## 🛠️ Tech Stack

- **Framework**: [React 19](https://react.dev/) + [Vite](https://vitejs.dev/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Motion & Physics**: [Framer Motion](https://www.framer.com/motion/)
- **Icons**: [Lucide React](https://lucide.dev/)

---

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher recommended)
- npm or yarn

### Installation
```bash
# Clone the repository
git clone https://github.com/RadenHanifAH/Portofolio.git

# Navigate into the project folder
cd Portofolio

# Install dependencies
npm install

# Start the development server
npm run dev
```

### Production Build
```bash
npm run build
npm run preview
```
